# Proyecto Google Sheets – Dashboard y análisis de KPIs

## Objetivo
Analizar indicadores de negocio mediante dashboards interactivos y visualización de datos en Google Sheets.

## Herramientas utilizadas
- Google Sheets
- Tablas dinámicas
- Fórmulas
- Dashboards
- Gráficos y visualización de datos

## Análisis realizado
Se trabajó con métricas de ventas y rendimiento utilizando tablas dinámicas, segmentación de datos y gráficos para identificar patrones y apoyar la toma de decisiones.

## Principales hallazgos
- Identificación de productos con mejor desempeño
- Comparación de ventas por región
- Seguimiento de KPIs comerciales

## Conclusión
El proyecto permitió desarrollar habilidades en análisis visual, organización de datos y construcción de dashboards para negocios.
