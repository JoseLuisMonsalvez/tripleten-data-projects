# Proyecto SQL – Análisis del desempeño financiero

## Objetivo
Analizar información financiera mediante consultas SQL para identificar patrones, tendencias y métricas relevantes para la toma de decisiones.

## Herramientas utilizadas
- SQL
- JOIN
- GROUP BY
- ORDER BY
- Funciones de agregación
- Análisis financiero

## Análisis realizado
Se trabajó con consultas SQL para analizar ingresos, gastos y rendimiento financiero. Se aplicaron filtros, agrupaciones y operaciones entre tablas para obtener información relevante.

## Principales hallazgos
- Identificación de patrones financieros
- Comparación entre categorías
- Evaluación de métricas de desempeño

## Conclusión
El proyecto permitió fortalecer habilidades en consultas SQL y análisis financiero aplicado a negocios.
